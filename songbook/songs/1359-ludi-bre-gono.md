## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Traditional outlaw (hajduk-style) song with two versions. 'Престегнал магаренцето' is my reading (he girded/saddled the donkey); 'малихера' I read as the Mannlicher rifle; Resava is a place name I could not verify.

**Words to learn**

| Macedonian | English |
| --- | --- |
| луди | crazy, wild |
| ајде | come on (filler/urging) |
| бре | hey (emphatic particle) |
| селаните | the villagers |
| Паша | Pasha, Ottoman official |
| магаренце | little donkey |
| се преправил | disguised himself |
| мариовец | man from Mariovo |
| ќебе | blanket (rough woollen) |
| малихера | Mannlicher rifle |
| ефенди | effendi, sir (Ottoman title) |
