## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Traditional revolutionary song about Gotse Delchev and the IMRO period, no author known. 'Дејгиди' I read as an encouraging exclamation ('onward'); 'блазе ле' I read as an endearment; both are my reading.

**Words to learn**

| Macedonian | English |
| --- | --- |
| собрале | they gathered |
| брдо | hill |
| поле | field, plain |
| војвода | voivode, rebel chieftain |
| дружина | company, band of comrades |
| комити | komitas, rebel fighters |
| дејгиди | onward (dialect exclamation, from ајде/дејгиди) |
| бомба | bomb |
| душмани | enemies |
| блазе | blessed one, dear one (my reading) |
