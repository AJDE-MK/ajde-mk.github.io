## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Traditional. 'Катиљ' is used teasingly; I rendered it 'murderous', which is my reading. Gjurgja is a woman's name (Georgia/Gjurgjica).

**Words to learn**

| Macedonian | English |
| --- | --- |
| пере | washes (laundry) |
| сејмен | gendarme, armed guard (Ottoman era) |
| меѓа | boundary, field edge |
| катиљ | murderer, cruel one (here: a teasing epithet) |
| кошула | shirt |
| кир | grime, dirt |
| фанала | caught, taken hold |
