## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Origin unclear; it may be a modern composition but I cannot name an author, so it is translated fully. 'Солунско' is the Thessaloniki region; Vrutok is the source of the Vardar.

**Words to learn**

| Macedonian | English |
| --- | --- |
| закопајте | bury (imperative) |
| никне | grows, sprouts |
| ѕвоно | bell |
| раскажува | tells, proclaims |
| душа | soul |
| сокол | falcon |
| бистра вода | clear water |
| пуста душа | poor soul (pusta = empty/poor) |
| исплачам | I weep out, cry over |
