## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Patriotic song, origin unclear, no author I can name. 'Гоцева лична убавица' is read as a reference to Gotse Delchev; 'Пиринка / Егејка / Вардарка' name the three parts of Macedonia.

**Words to learn**

| Macedonian | English |
| --- | --- |
| вистина | truth, it is true |
| мамо | mother (vocative) |
| распеана | singing, full of song |
| Илинден | St. Elijah's Day (2 August), Ilinden uprising |
| убавица | beauty |
| да горам | to burn |
| бликам | to gush, flash |
| горда | proud |
| расцутена | blossomed |
| Вардарка | woman from the Vardar region |
