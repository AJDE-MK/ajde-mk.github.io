## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Traditional revolutionary song about Gotse Delchev, no author known. 'Сека' and 'секо'' are dialect for 'секоја/секое' (every); 'шумка' I read as 'thicket, small grove'; my reading.

**Words to learn**

| Macedonian | English |
| --- | --- |
| развивај | spread out, unfurl |
| гора | forest |
| сенка | shade, shadow |
| знаме | banner, flag |
| слобода | freedom |
| одбор | chosen, select (also: committee) |
| бука | beech tree |
| јунак | hero |
| берданка | Berdan rifle |
