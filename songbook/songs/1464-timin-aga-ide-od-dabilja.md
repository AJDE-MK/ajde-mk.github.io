## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Dabilja is a place name. 'Правo си тегле' is my reading ('is heading straight'); it is dialect. Each line is sung twice. Origin unclear, looks traditional.

**Words to learn**

| Macedonian | English |
| --- | --- |
| ага | aga, landlord/lord (Ottoman title) |
| чифлик | estate, farm held by an aga |
| чифлиганите | the estate peasants/tenants |
| станале на нозе | stood up (lit. 'stood on feet') |
| се разлути | got angry |
| љуто | fiercely, bitterly |
| сечам | I cut, chop |
| тегле | heads for, pulls toward (my reading) |
