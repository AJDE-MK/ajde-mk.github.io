## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Traditional teasing song. 'Вендо' is a female name (Venda); I read the cosmetics as face powder and rouge.

**Words to learn**

| Macedonian | English |
| --- | --- |
| задевам | to tease, provoke |
| ерген | bachelor, unmarried man |
| помал брат | younger brother |
| ока | oka, old unit of weight (about 1.28 kg) |
| драм | dram, old unit of weight (about 3 g) |
| белило | whitening powder (cosmetic) |
| црвило | rouge, red cosmetic |
| тук' | just, only (dialect) |
