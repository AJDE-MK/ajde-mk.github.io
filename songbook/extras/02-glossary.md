# Glossary of words that keep coming back

Collected from Qwen's draft and your songbook. Meanings are as given there; I have not checked each one.

| Word | Meaning |
| --- | --- |
| лудо / луд | crazy (one in love); also "young lad" |
| либе | darling, sweetheart (both genders) |
| мома / моми | unmarried girl / girls |
| невеста | bride |
| ерген / беќар | bachelor |
| свекор / свекрва | father-in-law / mother-in-law (his parents) |
| саје (saj) | embroidered woolen apron-dress of Macedonian women's wear |
| капела | coin-studded bridal headdress |
| гајтан (gajtan) | braided silk trim on traditional jackets; used as a picture of perfect eyebrows |
| самовила (samovila) | Slavic forest or water fairy, beautiful and dangerous |
| славеј | nightingale |
| бело грло | "white throat": a golden singing voice |
| чифлиг / чифлик | farm, estate (Turkish *çiftlik*) |
| кабает (kabajet) | defect, flaw; also a fitted men's jacket |
| оро | circle dance (the oro "winds": *се вие*) |
| аман / леле / џанам / мале | emotional cries: "oh!", "alas!", "my soul!", a term of endearment |
| мори / море | filler and endearment, roughly "hey" or "my dear" |
| душо | "my soul", an endearment |
| калеш | Turkish loanword, "dark-eyed" or "black-haired" |
| чардак | an enclosed upper balcony |
| комити / комита | rebel fighters of the Ottoman era |
| војвода | leader of a rebel band |
| чалгија | the old urban band of violin, oud, kanun, clarinet and hand drum |
| зурла / тапан | folk oboe / large drum |
| печалба | work abroad to send money home |
