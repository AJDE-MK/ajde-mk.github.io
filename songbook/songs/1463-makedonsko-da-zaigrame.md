## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Modern folk-style song; origin unclear (no author I can name). 'Дај' before a plural verb is an urging particle, 'come on'.

**Words to learn**

| Macedonian | English |
| --- | --- |
| векови | centuries |
| оро | round dance |
| маки | troubles, hardships |
| кавал | kaval (end-blown flute) |
| гајда | bagpipe |
| зурла | zurla (loud double-reed pipe) |
| тапан | tapan (large drum) |
| засвирете | start playing (plural) |
| песнопојци | singers |
| играорци | dancers |
