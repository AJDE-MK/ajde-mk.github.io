## English

*Machine translation by Claude (my reading), not on Pesna.org and not checked by a native speaker. Treat it as a study aid.*

**Translator's notes.** Modern patriotic song; I cannot name an author, so origin unclear. The three rivers/mountains/sea (Vardar, Pirin, Aegean) stand for the three parts of geographic Macedonia; the 'Нека живеј' in the first refrain is a spelling variant of 'Нека живее'. Lines 3-6 of the third stanza are my reading.

**Words to learn**

| Macedonian | English |
| --- | --- |
| заборавај | forget (imperative) |
| роден крај | native land, home region |
| се бранува | ripples, waves (like grain or a flag) |
| земи ја | take it |
| вечна | eternal |
| нека живее | long live |
| маки | torments, hardships |
| солзи | tears |
| изникнати | sprung up, grown back |
